## Bộ cài 0.6.0 đã chuẩn bị

Lượt tiếp tục sau khi dọn build đã chạy `desktop/build-desktop.ps1 -Task package`
thành công. Bộ cài NSIS chứa WebView2 offline, có chữ ký updater tại:

- `dist/github-release/NetBridge_0.6.0_x64-setup.exe` (229.880.506 byte).
- `dist/github-release/NetBridge_0.6.0_x64-setup.exe.sig`.
- `dist/github-release/latest.json` và `SHA256SUMS.txt`.

`verify-local-release.py` xác minh 9 checksum, chữ ký, version được ký `0.6.0`
và từ chối dữ liệu bị sửa một byte. Kết quả lưu tại
`.qa/restore-mapping-2026-11-18/local-package-verification.json`.
Thu thập license của 306 Rust dependencies hoàn tất, không thiếu license text.

`actionlint` kiểm tra cả hai workflow với exit 0. Đọc `action.yml` từ GitHub API
theo đúng commit pin xác nhận checkout, setup-node, upload-artifact,
download-artifact và rust-cache đều dùng runtime `node24`. Bằng chứng:
`.qa/restore-mapping-2026-11-18/action-runtime-verification.json`.
Điều này chưa chứng minh cache hit hoặc workflow thực thi thành công trên runner.

nhưng helper `.qa/github-updater-2026-11-10/gh.py` sử dụng credential Git có sẵn
đã xác minh quyền push vào repository mà không in credential ra output.

Nội dung phát hành đã chuẩn bị tại
`.qa/restore-mapping-2026-11-18/release-notes.md`.
